# Data Wrangling Project 2

## Building the Portfolio Project

In project 2, you will carry out a few tasks related to building a portfolio project.  
The Data Tasks:

- [ ] Identify a source of data on the web.  **Describe your data and state who would be interested in it and why**.  Interest might be for management or business decision making reasons, scientific inquiry reasons, or public information reasons.  
- [ ] Create a data validation scheme for this data set and apply it.  Once the data is validated, archive it in an easily accessible way (such as a .csv file or SQL database, whichever is appropriate).  
- [ ] Create tables and plots to visualize your data.  Visualizations should accurately represent your data, should be relatively easy to understand, and should be aesthetically pleasing with respect to color choice.  You should include at least five visualizations.  At least one of the visualizations should be a map.

The Dashboard Tasks:

- [ ] Create a dashboard that allows users to interact with your data set.  Your dashboard code should load your data set and create the visualizations discussed above.  
- [ ] Include at least five interactive elements: dropdowns, sliders, tabs in the dashboard, etc.  *Note that this is a minimum.  For many visualizations you will want to create several interactive elements, so you might use 15-20 interactive elements.*  
- [ ] Create a layout (or layouts if using different tabs) that is easy to understand and clearly separates different areas of the dashboard one from the other.  
- [ ] Your dashboard should contain explanatory text, visualizations, and supporting images as appropriate.

What are the deliverables for your project?

- [ ] Publicly available dashboard presentation of your project.    
- [ ] Github repository containing the data set, your dashboard code, any code you used to acquire and clean your data and build any visualizations and models, and supporting files such as pickled models or similar.  Your github repo should contain an explanatory readme.md file in its home directory describing your project.  
- [ ] A brief (5 minutes) presentation of your project during the final exam period for the class.

Grading?  Each checkbox item above is graded on a 0-1-2 point scale and there are a total of 20 points possible on this project.
